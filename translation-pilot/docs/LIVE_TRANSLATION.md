Use [ROUND4_HANDOFF.md](ROUND4_HANDOFF.md) for provider setup, private configuration, the same-origin private PHP Codespaces test, packaging, production deployment and known limits. GitHub Pages supports preview captions, but cannot run the PHP backend.
