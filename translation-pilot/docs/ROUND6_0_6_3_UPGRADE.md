# v0.6.3 — compact library and immediate content selection

This is the user-requested follow-up to combined Round 6 Batches 2 and 3, on Round-6-Development. It replaces the v0.6.2 rules that all new content starts unenrolled and that Delete only archives. No later batch, deployment, default-branch merge or production Node service.

## Upload to the existing site

1. Back up current files/database and update between meetings. Download Round-6-Development as ZIP and extract it.
2. **If migration 005 is already installed (v0.6.2), no SQL is needed. Do not run 005 again.** If upgrading from v0.6.1 or earlier, follow ROUND6_BATCH2_3_UPGRADE.md to install 005 once on the existing database with 001–004 already installed. No migration 006 and no starter-data import.
3. Merge only **hosting-update/public_html contents** into the existing domain document root. Keep the live **server-paths.php, config.js and root .htaccess**, private configuration/provider keys, database, media storage and its corrected media_dir path/permissions. Never replace these with examples. API/translation-api directory rewrite files remain included as before.
4. Close/reopen online and confirm **0.6.3** in Settings. Reopen again after service-worker installation if necessary. Do not clear browser/site storage.

## Changed behavior

- Content library returns to compact rows: title/category/library, tags, last-used date, use count, and Edit content on the right (View content for contributors without shared-edit permission). Rotation and deletion controls are inside that editor so they do not increase row height. Small media thumbnails remain; text has no thumbnail. Existing search/type/tag/archive filters and list/grid views remain available.
- Meeting Change content keeps visual thumbnails for images/video. Only videos get a play button, in the thumbnail's bottom-right corner. Text shows an excerpt and See Full Text. Ordinary links open their original website. Each item has one **Use content** button that immediately replaces the slide's content with that single item and closes the picker. No checkboxes, batch-use footer, separate Preview button or rotation-management buttons in the picker. Search/category/scroll state is retained when returning from full text/video, and closing video unloads playback. Existing saved/template multi-item slides remain intact until their content is explicitly replaced; this does not redesign the template slide-type system.
- New content automatically joins **only the signed-in fixed location's rotation**, when shared/available there, in the same PHP transaction as creation. Other locations see it if shared but decide independently whether to enroll it. An Administrator's new content joins the currently selected location. Unassigned Content Manager/Report Viewer accounts can still contribute but have no personal location rotation and gain no cross-location management rights; the form explains this. Sharing exclusively elsewhere does not enroll an unavailable creator location. Existing items and edits do not get silently re-enrolled. Imports use the same creation rule.
- Administrator Delete content asks **Yes, archive / No, delete permanently / Cancel**. Cancel/Escape does nothing. Archive removes content from active pools and keeps it under Show archived content. Archived items offer Delete permanently. Both paths are administrator-only in PHP and use version checks. Permanent deletion removes the current library record, its edit versions and all rotation memberships, and sends a sync tombstone so other devices remove it too. Explicit live template content-ID references are pruned using normal versioned template saves; saved meetings/completed history remain unchanged. Referenced shared media is retained; this is not a media purge or removal of historical meeting snapshots. Temporary meeting-upload cleanup remains unchanged.
- English/Spanish interface text supported. All authenticated contribution rights, location boundaries, original required fields, saved presentation/transcript behavior and protected PHP media storage are retained.

- Administrator: delete a test item; Cancel first, then Yes, archive. Find it under Show archived content and delete it permanently. On another test item choose No, delete permanently directly. Confirm a saved meeting that used it and its media still opens.
