# Round 6 combined Batches 2 and 3 — v0.6.2

For the existing PHP/MySQL site with migrations 001–004 installed. Production remains static HTML/CSS/JavaScript plus PHP/MySQL. No Node service or video transcoder is required. Do not upload the repository root demo or full-install hosting-upload over the live site.

## Back up, migrate, upload

1. Download the **Round-6-Development** branch ZIP. Back up the current application files and database. Ask presenters to finish/close meetings during this short update so no one creates content between the migration snapshot and app upload.
2. In cPanel **phpMyAdmin**, select the existing MMB database. Check `schema_migrations`: versions 1–4 must already exist. If version 5 is absent, import **hosting-update/database/005_content_rotation.sql once**. It creates one rotation table and snapshots existing active content into each enabled location where its item AND parent library targeting allow it. It does not rewrite existing content, meetings, usage, locations or media. Do not import starter data or old migrations. Do not rerun this SQL after version 5 exists. If an import fails, inspect the error and table/version state before retrying; MySQL DDL is not transactional.
3. Merge **only the contents of hosting-update/public_html/** into the existing domain document root, overwriting matching application files and merging subdirectories. Do not delete/replace the document-root folder. The update deliberately excludes live **server-paths.php, config.js, and root .htaccess**. Keep those, all private configs/provider keys, and the corrected private media_dir path/permissions. API and translation-api directory rewrite files remain included as before. Never copy an example private config over the working config.
4. Close other MMB tabs, reopen online, and confirm **0.6.2** in Settings. Reopen again if the old service worker still shows the earlier version. Do not clear site storage. Existing unstarted drafts can use Change content/Auto-select; selected snapshots are not silently replaced.

CLI alternative for a developer: use the repository's `php scripts/migrate.php /absolute/path/to/the-existing-private-config.php`; it skips installed migrations. Keep scripts and SQL outside the public document root. This CLI alternative needs the source database/migrations directory; the cPanel update folder is intended for the phpMyAdmin method above.

## Product and data rules

- Every signed-in role can contribute Text, Image/Video and Link content to company libraries. Editing existing shared content and library management retain Administrator/Content Manager permissions. Subject tags are independent of location sharing. All user interface additions support English/Spanish; user-authored content is not automatically translated.
- Text requires a title/body. Image/Video requires a title/file; Link requires a title/valid HTTP(S) URL. Accompanying media/link text is optional in this update. Legacy types retain IDs/references and map to the three display categories; saving an edited legacy item normalizes its category without discarding its relevant body/media/link.
- **All** includes enabled current and future locations; individual selections include only the selected IDs. At least one receiving location is required. Existing parent-library targeting still restricts availability. A newly created location can browse All-shared content but starts with an empty rotation.
- **Available content** can be manually used without enrollment. **Our rotation** is server-held per location and controls future automatic selection. Migration 005 preserves the pre-upgrade pool once. New items start outside every rotation. Removing membership does not remove availability. Revoking an item's sharing removes that location's membership; sharing again requires opt-in again.
- Location accounts manage only their assigned location. Administrators manage the selected location. Unassigned Content Managers/Report Viewers can browse using the existing Meeting location selector but do not gain rotation-management rights. While editing a meeting, its actual location is used and the global location selector is pinned until the editor closes. Explicit saved-template/manual content choices may use available content without enrollment; automatic choices require enrollment. No unenrolled fallback.
- **Delete content for everyone** is administrator-only. It archives content and clears its future rotation membership. Saved draft/completed meeting snapshots and shared assets remain intact. Temporary meeting-upload confirmed-completion cleanup is unchanged. No shared media is physically deleted by this action.
- Reusable library uploads accept JPEG/PNG/WebP and MP4/WebM. Use H.264 MP4 or VP8/VP9 WebM supported by the device; browser decoding is checked before saving a new video. No conversion occurs. Defaults: images 15 MiB, shared videos 50 MiB; existing PHP upload/post limits can be lower and are respected. Optional private `max_library_video_bytes` can change the application video cap; no private config edit is required. Posters are optional browser-generated JPEGs. Older QuickTime temporary meeting uploads are unchanged; new reusable MOV uploads are rejected clearly.
- YouTube links use the existing player; ordinary websites open as links. Thumbnails are lazy-loaded, selectors initially show 30 matching items, previews do not record use/enroll content, and playback unloads on close. Protected media previews and online videos need connectivity; presentation offline-media caching remains unchanged. Codec/device/YouTube embedding restrictions can still prevent playback and get visible feedback.

## Short manual checklist

- Location A: add Text with All, an image, and a supported short video. Confirm save and preview. New content is Available only; manually use it in Morning movement without enrollment. Check empty rotation then Add to our rotation and Auto-select. Reload/another device should retain membership.
- Location B: the same All item is available but its new membership is independent. Enroll it in B, remove it in A, and confirm B stays enrolled. Create an item shared only to B; A must not list it. Test All/individual/partial checkbox states and an empty selection error with entered values retained.
- Administrator: choose A then B in the existing location selector and manage each independently. Delete a named test item for everyone; confirm active selectors lose it while a saved/completed meeting using it and its media still opens. Confirm a location account has no company-deletion action.
- In Stretches/Morning movement, browse legacy text/images/YouTube links. Preview, return to the same search/filter/scroll, and choose content. Close video previews and confirm sound stops. Confirm no usage count increases from preview alone.
- On desktop, portrait phone and landscape phone, check cards, inline errors, confirmations and navigation. Switch to Spanish and check the editor/rotation labels. Open an existing saved presentation and confirm media, translation/captions and history on your real device.

Unexpected failures retain a request ID; record it with the action/role/file size, never private config or keys. No paid translation-provider calls or live deployment were performed for verification.

## Rollback

Keep Round-5-Development and the v0.6.1 application backup available. Restore matching backed-up application files while retaining live configuration/media. Migration 005 is additive; leave its table/version installed. Older releases do not enforce the new rotation/sharing rules or support reusable video records fully, so rollback is a temporary operational measure. Do not drop tables or restore an old database over newer meetings/content without a separately planned data recovery.
